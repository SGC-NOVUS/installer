# Changelog

Все значимые изменения инсталлятора `novus-installer` документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/);
проект строго следует [SemVer 2.0.0](https://semver.org/lang/ru/) в линейке `0.x.y` (Раздел 8 AGENTS.md).

## [Unreleased]

## [0.1.0] — 2026-07-18

### Added
- Полный пакет архитектурной и технической документации в директории `docs/` (Architecture, API, Install Steps, Security, Rollback, Frontend, Development).
- Интерактивный Web-Wizard первичной настройки на Vue 3 и Tailwind CSS (SPA с live-стримингом терминала xterm.js по WebSocket).
- Двухуровневая стратегия отката (Soft rollback созданных конфигураций/сертификатов и Hard rollback через `cleanup.sh`).
- Пакет `internal/version` со стандартизированным SemVer 2.0.0 версионированием и `-ldflags`.
- Preflight валидация окружения для Ubuntu 22.04/24.04 и Debian 12.
- Автоматический pairing локального агента `novus-agent`.
- Генерация криптографических конвертов секретов (master envelope, canary).

### Changed
- Устранен произвольный хардкод версии 1.0.0; проект переведен на честный pre-release `0.1.0-dev`.
- Улучшена обработка ошибок PTY выполнения команд при установке пакетов.

### Security
- Изоляция секретов в `/etc/novus/secrets` с правами доступа `0750` / `0640`.
- Защита канарейки от подделки через сверку с PHP-рантаймом панели.

## [0.0.6] — 2026-06-20

### Added
- Шаг автоматического сопряжения (auto-pair) локального демона `novus-agent` с разворачиваемой панелью.
- Автоматическая инициализация учетной записи супер-администратора (identity bootstrap).
- Загрузка учетных данных установки через плавающий баннер в UI с поддержкой скачивания Blob/data URI в обход CSP.

### Fixed
- Генерация канарейки (canary) через нативный PHP CLI для 100% совпадения алгоритма хеширования с ядром панели.
- Разрешение прав чтения скрипта canary для пользователя `www-data` и очистка устаревших emergency-блокировок.

## [0.0.5] — 2026-06-19

### Added
- Механизм отката (rollback cleanup) и сценарий `cleanup.sh` для полного сброса окружения VPS при сбое установки.
- Автоматическое выключение процесса инсталлятора (auto-shutdown) после завершения всех шагов развертывания.

### Fixed
- Исправление переопределения systemd drop-in для PHP-FPM, вызывавшего ошибку 502 Bad Gateway.
- Корректная обработка распаковки вложенных поддиректорий из архивов GitHub zipball.
- Изоляция пользователей БД MariaDB на `127.0.0.1` с аварийным fallback на root пароль.

## [0.0.4] — 2026-06-19

### Added
- Автоматическая установка и запуск `composer install` перед запуском миграций Artisan.
- Автоматическое временное отключение несовместимого расширения `grpc` перед выполнением консольных команд Artisan.
- Безопасное выполнение SQL скриптов MariaDB через конвейер `stdin` без утечки паролей в командную строку shell.

### Fixed
- Устранена ошибка перехвата системных вызовов `pkill`, приводившая к завершению собственного процесса apt.
- Корректное определение конфигурационных ini-файлов расширений PHP с помощью `sed`.

## [0.0.3] — 2026-06-18

### Added
- Enterprise-редизайн веб-интерфейса мастера установки (Tailwind CSS, темная тема, маскирование секретов в окне консоли).
- Интеграция системных компонентов: Redis, Supervisor, Fail2Ban, межсетевого экрана UFW и системного cron.
- Добавление обязательных расширений PHP: `grpc`, `redis`, `intl`, `gd`, `bcmath`.
- Автоматическое подключение официальных системных репозиториев для PHP, MariaDB и Redis.

### Security
- Маскирование конфиденциальных токенов, ключей и паролей в реальном времени при трансляции логов установки в Web UI.

## [0.0.2] — 2026-06-17

### Added
- Поддержка дистрибутивов Ubuntu 22.04/24.04/26.04 и Debian 12/13.
- Автоматическая очистка поврежденных и устаревших репозиториев APT перед началом установки.
- Механизм получения GitHub Personal Access Token (PAT) из переменных окружения, CLI и формы веб-мастера.

### Fixed
- Переход на единую поддерживаемую версию PHP 8.5.
- Устранение обрезки левой границы терминала веб-интерфейса и улучшение ANSI-подсветки.

## [0.0.1] — 2026-06-17

### Added
- Первоначальный установочный скрипт `install.sh` для развертывания платформы NOVUS.
- Базовая preflight-проверка системных требований (ОЗУ, CPU, свободное место на диске).
- Скачивание и компиляция ядра инсталлятора, копирование бинарного файла в `/usr/local/bin/novus-installer`.
- Базовый пайплайн скачивания приватного ядра панели и последнего публичного бинарника агента.
